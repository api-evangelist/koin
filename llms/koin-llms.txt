- [Card](https://api-docs.koin.com.br/reference/card.md)
- [Pix](https://api-docs.koin.com.br/reference/pix.md)
- [Create Payment](https://api-docs.koin.com.br/reference/createpayment.md): Create payment service. Before required fields will validated and after will validated business rules. Below is a table with the information regarding said api.
- [Get Payment by Reference ID](https://api-docs.koin.com.br/reference/paymentbyreferenceidget.md): Payment details service.
- [Get Payments by Transaction ID](https://api-docs.koin.com.br/reference/paymentbytransactionidget.md): Payment orders.
- [Capture Payment](https://api-docs.koin.com.br/reference/capturepayment.md): Service responsible for capturing a card payment
- [Get Payment](https://api-docs.koin.com.br/reference/paymentbyorderidget.md): Payment details service.
- [Cancel Payment](https://api-docs.koin.com.br/reference/cancelpaymentput.md): Cancellation payment. Card, Pix and BNPL payment method can be cancelled, for Pix payment method, you can only cancel dynamic QR payments; for the card payment method, you can cancel **Opened** or **Authorized** payments, which will remain with the status **Canceled** or **Voided** respectively.
- [Pix](https://api-docs.koin.com.br/reference/pix-1.md)
- [Crypto](https://api-docs.koin.com.br/reference/crypto.md): Payout with cryptocurrency
- [Available Cryptocurrencies](https://api-docs.koin.com.br/reference/getcurrenciespost.md): Service only for crypto payout. It will return the possible cryptocurrencies that the account is allowed to transact.
- [Cryptocurrency Quotations](https://api-docs.koin.com.br/reference/getquotationspost.md): Service only for crypto payout. It will return the quote for the selected cryptocurrency
- [Create Payout](https://api-docs.koin.com.br/reference/createpayoutpost.md): In the payout service creation, all the required fields will be validated at first, after that, business validation rules will be run. The next table shows the information about the API.
- [Get Payout by Reference ID](https://api-docs.koin.com.br/reference/payoutbyreferenceidget.md): Payout details service.
- [Get Payout](https://api-docs.koin.com.br/reference/payoutbypayoutid.md): Payout details service.
- [Create Refund](https://api-docs.koin.com.br/reference/createrefundputbyorderid.md): Service responsible for requesting the return of an approved payment. The refund may be total or partial.
- [Get Refund](https://api-docs.koin.com.br/reference/consultrefundget.md): Service to get a previously generated refund.
- [Availability](https://api-docs.koin.com.br/reference/availabilitypost.md): You can use this service to check if the customer is eligible for the "buy now pay later" payment method. The service will return the installment options in case of success. It is available for transparent checkout only.
- [Payment Sale](https://api-docs.koin.com.br/reference/notificationpost.md): Receiving notifications of a sale finalized.
- [Recipient Account](https://api-docs.koin.com.br/reference/recipientaccountpost.md): Service to obtain recipient account information.
- [Notification webhooks](https://api-docs.koin.com.br/reference/webhook.md): Notified payment transactions
- [Send notifications to Koin](https://api-docs.koin.com.br/reference/send-notifications.md): API to send notifications to Koin about an existing transaction.
- [Koin Checkout SDK](https://api-docs.koin.com.br/reference/koin-checkout-sdk.md)
- [Validate account](https://api-docs.koin.com.br/reference/validateaccountpost.md): Validate account for communications
- [Use Cases](https://api-docs.koin.com.br/reference/use-cases.md): This section provides example use cases of how the API you create interacts with the Koin API and what the communication flow with acquirers (PSP) should look like.
- [Create Pre-Evaluation](https://api-docs.koin.com.br/reference/createpreevaluationusingpost.md): Receives a new transaction for antifraud analysis, its meant to be used before payment authorization.
- [Create Evaluation](https://api-docs.koin.com.br/reference/createevaluationusingpost.md): Receives a new transaction for antifraud analysis, if used with pre-evaluation it should be called after the payment authorization. Its mandatory to reuse the reference_id from pre-evaluation.
- [Strategies](https://api-docs.koin.com.br/reference/strategies.md)
- [Create Evaluation](https://api-docs.koin.com.br/reference/createevaluationusingpost-1.md): Receives a new transaction for antifraud analysis.
- [Create Evaluation](https://api-docs.koin.com.br/reference/createwiretransferusingpost.md): Receives a new transaction for antifraud analysis.
- [Create Evaluation](https://api-docs.koin.com.br/reference/atoevaluationusingpost-1.md): Receives a new transaction to evaluate Account Take Over request
- [Send Notifications](https://api-docs.koin.com.br/reference/sendaccounttakeoverupdatesusingpatch.md): API to send updates about an existing case.
- [Retrieve Evaluation Status](https://api-docs.koin.com.br/reference/evaluationstatususingget-1.md): API to retrieve the status of an antifraud evaluation.
- [Cancel Evaluation](https://api-docs.koin.com.br/reference/cancelevaluationusingdelete-1.md): API to notify if the order was canceled either by the store or the buyer before completition of the Antifraud analysis. The query parameter in the URL :id Could be either Evaluation ID returned by api on evaluation :evaluationId or reference id sent by client on evaluation :store.referenceId
- [Send Notifications](https://api-docs.koin.com.br/reference/sendevaluationupdatesusingpatch.md): API to send notifications about an evaluated transaction. The types of notifications: - RFI: Notify a request for information (internal, from a bank, or from any entity) - Chargeback: Notify a chargeback (internal, from a bank, or from any entity) - Status     - Collected: Transaction payment was settled    - Not Collected: Transaction payments was failed    - Cancelled: Transaction was cancelled    - Finalized: Transaction finalized OK    - Refunded: Transaction payment was refunded    - Authorized: Transaction payment was authorized    - Recovering: In case a strategy has been applied, informs the result. See [Strategies](https://api-koin.readme.io/reference/strategies) - Info: Other type of information
